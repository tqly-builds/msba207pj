# Business Analytics Coursework

This repository contains applied analytics assignments using logistic regression to study consumer-loan acceptance and small-business loan default risk.

## Projects

- **Universal Bank loan acceptance** — Prepare customer data, compare four scikit-learn logistic regression configurations, and fit a binomial GLM with `statsmodels`. Review model coefficients, standard errors, and AIC.
- **SBA loan default** — Fit and interpret binomial GLM models, generate default-risk probabilities for a held-out group, and assess classifications with a confusion table and misclassification rate.

## Skills demonstrated

Python data preparation with pandas and NumPy; categorical-variable encoding; train/test workflows; logistic regression and GLM modeling; interpreting model estimates and statistical summaries; and classification evaluation.

## Tools

Python, Jupyter, pandas, NumPy, scikit-learn, statsmodels, Matplotlib, and Seaborn.

Install the main dependencies with:

```bash
pip install pandas numpy scikit-learn statsmodels matplotlib seaborn
```

The analyses are coursework examples and should not be treated as production lending or credit decisions.
